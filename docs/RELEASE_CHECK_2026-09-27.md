# v2.0 배포 전 점검 — 2026-09-27

## 이번에 수정한 문제

- 열람 비밀번호로 편집 중 편집 권한을 변경하면 저장 인증이 누락될 수 있던 문제: 저장된 인증값과 새 비밀번호 입력값을 분리했다.
- 저장 응답을 기다리는 동안 바꾼 여행 설정이 이전 값으로 돌아갈 수 있던 문제: 이후 편집을 보존하고 추가 저장 안내를 표시한다.
- 변경하지 않은 비밀번호를 자동저장마다 다시 보내던 동작을 제거했다.
- 불러오기 실패·잠금 상태에서 편집하거나 예시 장소로 덮어쓰지 않도록 저장과 편집 도구를 차단했다.
- 새 계획 날짜를 고정된 9월 19~20일 대신 기기의 오늘~내일로 설정한다. 잘못된 날짜·빈 여행지·367일 초과 일정은 저장 전에 안내한다.
- 계획 검색에서 늦게 도착한 이전 응답이 최신 결과를 덮지 않도록 했다. 최초 중복 요청도 제거했다.
- 네이버 지도 재생성 시 이전 인스턴스를 정리한다. 개발 중 컨트롤 중복을 확인했으며 SDK의 destroy()를 사용했다.
- 작성자만 편집 권한에서 브라우저 저장정보를 지우면 편집 접근을 잃을 수 있음을 안내한다. 열람 비밀번호는 편집 권한을 복구하지 않는다.
- 저장하지 않은 비밀번호 변경도 페이지 이탈 경고에 포함한다.

회귀검사는 실제 저장 API와 임시 메모리 DB를 사용한다. 관리자/작성자/열람자 권한, 비밀번호 변경, 잘못된 데이터 거부, 동시 저장 충돌 사본, 삭제 충돌, 복원/7일 만료, 사용자 지정 핀 색상·거점·유류비·여행지 엮기 값 보존을 검사한다. 운영 계획은 수정하거나 삭제하지 않았다.

## 남은 검증 범위

- 화면 크기 변경 검사는 실제 Samsung Internet/iOS Safari 및 한글 모바일 키보드 검사를 대신하지 않는다.
- 다수 사용자 부하 시험, 외부 지도/API 장애 시험, 장시간 운영 시험은 수행하지 않았다. 무제한 사용자 수용이나 장기 무장애를 보장하는 결과가 아니다.
- 무료 서비스 한도·지도 데이터 품질·외부 서비스 가용성은 운영 중 별도 확인이 필요하다.
- 빌드에는 일부 클라이언트 번들이 500 kB를 넘는 경고가 남아 있다. 기능 실패는 아니지만 저속 모바일망의 첫 로딩 최적화 여지가 있다.
- 로컬 개발 DB 미설정으로 브라우저 자동저장 HTTP 성공은 확인하지 못했다. 저장 기능은 위 임시 DB API 회귀검사로 검증했다.

이번 요청은 배포 전 점검이므로 운영 배포는 실행하지 않았다. 유료 리소스나 요금제를 추가하지 않았다.
